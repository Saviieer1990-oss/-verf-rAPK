# ÖverförAPK

En fristående Android-app för att samla APK-filer, hämta appbyggen från GitHub och installera appar på Android TV-enheter över det lokala nätverket.

## Projektstatus

Detta repo innehåller projektets Android-källkod. Funktioner som ännu inte är färdigimplementerade eller verifierade markeras tydligt i appen och dokumentationen.

## Bygg

GitHub Actions bygger debug-APK automatiskt vid push till `main` och kan köras manuellt via Actions.
